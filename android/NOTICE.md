# Olimora Android data notices

The bundled `turkey_locations.json` asset is generated from:

- `turkey-geo-api` v1.3.0, MIT License: https://github.com/onurusluca/turkey-geo-api
- GeoNames `TR.zip`, Creative Commons Attribution 4.0: https://www.geonames.org/

GeoNames coordinates use WGS84. The generated asset contains only the fields
needed for Olimora's Türkiye province and district picker.
